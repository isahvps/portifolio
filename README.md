# Portfólio — Serviços Digitais sob Encomenda

Site responsivo para apresentar serviços digitais e receber pedidos. Feito com HTML, CSS e JavaScript, sem dependências de instalação.

## Como personalizar

1. Abra `index.html`.
2. Troque o texto, caso queira mudar a descrição dos serviços.
3. No link do botão de contato, substitua `https://wa.me/SEUNUMERO` pelo link do seu WhatsApp, usando somente números e incluindo `55`, DDD e número. Não publique seu número se não quiser recebê-los por WhatsApp.
4. Os projetos da seção “Alguns exemplos” são demonstrações. Troque-os por projetos seus ou mantenha o aviso de que são exemplos.
5. Se não quiser usar WhatsApp, troque o link do botão por outro canal de contato.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `portfolio-servicos`.
2. Envie os quatro arquivos (`index.html`, `style.css`, `script.js` e `README.md`) para a raiz do repositório.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde a publicação e abra o endereço mostrado em **Settings → Pages**.

Não coloque senhas, documentos pessoais ou dados privados nos arquivos do site.
